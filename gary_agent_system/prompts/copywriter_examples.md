## ⚡ Dicas para Prompts Perfeitos

### Estrutura Ideal
```
tipo|prompt|público|tom|requisitos específicos|CTA desejado
```

### Elementos que Funcionam
- **Números específicos**: "aumente 47%", "em 30 dias", "R$10k para R$50k"
- **Urgência real**: "vagas limitadas", "prazo X dias", "edição especial"
- **Prova social**: "500+ empresas", "Fortune 500", "cases reais"
- **Transformação clara**: "de X para Y", "do problema à solução"
- **CTA único**: uma única ação, específica, com benefício

### Tom NTEX em Prompts
- Use: "direto", "sem jargões", "punchy", "zero buzzwords"
- Evite: "inovar", "sinergia", "paradigma", "disruptivo"
- Prefira: "vende mais", "gasta menos", "resultado rápido", "simples"
