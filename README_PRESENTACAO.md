# Apresentação NTEX → Kabatec

## 📋 Sobre

Apresentação moderna e interativa da proposta comercial da NTEX para a Kabatec, focada no piloto de academias com R$ 3.000/mês.

## 🚀 Tecnologias Utilizadas

- **Tailwind CSS** - Framework de estilização moderna
- **Three.js** - Background animado com partículas 3D
- **GSAP** - Animações suaves e profissionais
- **HTML5/CSS3** - Estrutura e estilos avançados

## 📁 Arquivos

- `proposta_kabatec_modern.html` - Apresentação principal
- `proposta_kabatec.html` - Versão original (simples)

## 🎯 Como Usar

### 1. Abrir a Apresentação
```bash
# Abrir no navegador
open proposta_kabatec_modern.html
```

### 2. Navegação
- **Teclado**: Setas ← → ou Espaço
- **Mouse**: Clique nos pontos de navegação (lateral direita)
- **Touch**: Swipe esquerda/direita em dispositivos móveis

### 3. Controles
- **F11**: Tela cheia
- **ESC**: Sair da tela cheia
- **Ctrl + R**: Recarregar
