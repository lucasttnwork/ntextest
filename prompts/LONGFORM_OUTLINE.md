### Como Usar Este Prompt (Explicação Simples para Humanos)

- **Para que serve?**: Criar um outline claro e modular para blog, email ou página.
- **Quem deve usar?**: Conteúdo, SEO e produto.
- **O que ele faz?**: Gera H1, H2 e bullets com provas e CTA.
- **Como usar na prática?**
  1) Copie o prompt abaixo.
  2) Cole na IA e preencha `{{tema}}`, `{{avatar}}`, `{{proposta_valor}}`, `{{CTA}}`.
  3) Ajuste as seções conforme o canal.
- **O que esperar como resultado?**: Estrutura pronta para escrever o texto final.
- **Como se encaixa no processo NTEX?**: Base para `sops/03_producao_de_ativos.md` e `prompts/LP_BLUEPRINT.md`.

# LONGFORM_OUTLINE

**Objetivo:** criar outline modular para blog/e-mail/página.

**Entrada**
- `{{tema}}`, `{{avatar}}`, `{{proposta_valor}}`, `{{CTA}}`

**Saída**
- Título H1
- Seções H2 (3–7), cada uma com bullets de argumentos, provas e callouts
- FAQ (5–7)
- CTA final

**Notas**
- Frases curtas. Sem jargão. Evitar metáforas.
