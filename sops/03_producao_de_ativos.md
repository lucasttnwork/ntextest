# SOP 03: Produção de Ativos — O que fazemos aqui?

## O que fazemos aqui?
Criar materiais visuais, web e conteúdo para executar a estratégia de marketing.

## Até onde este processo vai (e o que ele não faz)?
**Inclui**: Branding, desenvolvimento web, conteúdo com IA, otimização SEO
**Exclui**: Distribuição de campanhas, análise de resultados

## Quem faz o quê?
- **Responsável (R)**: Designer/Desenvolvedor
- **Aprovador (A)**: Diretor criativo
- **Consultados (C)**: Cliente, estrategista
- **Informados (I)**: Equipe de distribuição, gestão

## O que precisamos para começar?
- **Triggers**: Estratégia aprovada, briefings de produção
- **Dados necessários**: Guia de marca, estratégia de conteúdo
- **Referências**: Moodboard, exemplos de concorrentes

## Quais ferramentas usamos (e para que servem)?
- **Apps principais**: Figma, Canva, WordPress, Midjourney, ChatGPT
- **Chaves/API**: OpenAI, ferramentas de design
- **Integrações**: Airtable, CRM, ferramentas de IA
- **IA**: Geração de texto, imagens, otimização

## Procedimento (checklist)

### 1. Preparação
- [ ] Revisar briefings de produção
- [ ] Configurar ferramentas de design
- [ ] Preparar templates e assets
- [ ] Validar cronograma

### 2. Execução
- [ ] **Branding e Design**:
  - [ ] Criar logotipo principal
  - [ ] Desenvolver paleta de cores
  - [ ] Selecionar tipografias
  - [ ] Criar guia de marca completo
  - [ ] Preparar arquivos em múltiplos formatos

- [ ] **Desenvolvimento Web**:
  - [ ] Criar site/landing pages
  - [ ] Implementar SEO técnico
  - [ ] Integrar analytics (GA4)
  - [ ] Configurar testes de conversão
  - [ ] Otimizar para mobile

- [ ] **Conteúdo com IA**:
  - [ ] Gerar textos com LLMs
    - [ ] Aderir rigorosamente às diretrizes de copy da NTEX (vide `prompts/BUILD_SOCIAL_POST.md` e `prompts/LONGFORM_OUTLINE.md`): direto, punchy, sem metáforas, valor primeiro
  - [ ] Criar imagens com IA
    - [ ] Garantir consistência com o tom e mensagens definidas; evitar textos em imagem que quebrem as regras de copy
  - [ ] Desenvolver scripts para vídeos
  - [ ] Implementar testes A/B automáticos
  - [ ] Personalizar conteúdo por segmento

### 3. Validação
- [ ] Revisar qualidade dos materiais
  - [ ] Revisão crítica da qualidade e consistência da copy (aderência a tom e estilo NTEX)
- [ ] Testar funcionalidade web
- [ ] Validar com cliente
- [ ] Aprovar para distribuição

### 4. Entrega
- [ ] Organizar arquivos finais
- [ ] Documentar especificações
- [ ] Preparar para distribuição
- [ ] Atualizar status no CRM

## O que entregamos ao final?
- **Artefatos gerados**: Logotipo, site, conteúdo, guia de marca
- **Formatos**: PNG, SVG, PDF, HTML, MP4
- **Status**: Ativos aprovados, prontos para distribuição

## Quando está pronto e aprovado?
- [ ] Logotipo em múltiplos formatos
- [ ] Site funcional e responsivo
- [ ] Conteúdo aprovado pelo cliente
- [ ] SEO implementado
- [ ] Testes de conversão configurados

## Prazos e escalonamento (SLA)
- **Prazos típicos**: 10-15 dias úteis
- **Urgência**: Média
- **Escalonamento**: Diretor após 12 dias

## Como medimos sucesso?
- **KPIs**: Tempo de produção, qualidade dos materiais
- **Metas**: 95% de aprovação, máximo 15 dias
- **Fonte de dados**: Airtable, feedback do cliente

## O que é automático (e o que precisa de humano)?
- **Triggers**: Briefing aprovado
- **Ações**: Geração automática de conteúdo
- **Erros comuns**: Qualidade insuficiente, cliente não disponível
- **Retentativas**: 2 revisões por material
- **Human-in-the-loop**: Aprovação de design, validação final

## Integrações
- **Figma**: Design colaborativo
- **WordPress**: Desenvolvimento web
- **OpenAI**: Geração de conteúdo
- **Midjourney**: Criação de imagens
- **Airtable**: Gestão de projetos
