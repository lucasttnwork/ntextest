# SOP 02: Destilação e Ideação — O que fazemos aqui?

## O que fazemos aqui?
Transformar informações coletadas em estratégia de marca e plano de marketing executável.

## Até onde este processo vai (e o que ele não faz)?
**Inclui**: Posicionamento, público-alvo, tom de voz, moodboard, planejamento de canais
**Exclui**: Criação de materiais visuais, execução de campanhas

## Quem faz o quê?
- **Responsável (R)**: Estrategista de marca
- **Aprovador (A)**: Diretor criativo
- **Consultados (C)**: Cliente, equipe de design
- **Informados (I)**: Equipe de produção, gestão

## O que precisamos para começar?
- **Triggers**: Briefing aprovado, informações validadas
- **Dados necessários**: Briefing completo, análise de concorrentes
- **Referências**: Exemplos de marcas similares, tendências do setor

## Quais ferramentas usamos (e para que servem)?
- **Apps principais**: Figma, Canva, Miro, Google Docs
- **Chaves/API**: Ferramentas de pesquisa de mercado
- **Integrações**: Airtable para documentação
- **IA**: Análise de tendências, geração de insights

## Procedimento (checklist)

### 1. Preparação
- [ ] Revisar briefing completo
- [ ] Organizar referências e exemplos
- [ ] Configurar ferramentas de colaboração
- [ ] Agendar sessão de ideação

### 2. Execução
- [ ] **Estratégia de marca**:
  - [ ] Definir posicionamento único
  - [ ] Estabelecer proposta de valor
  - [ ] Mapear público-alvo detalhado
  - [ ] Definir tom de voz e personalidade
    - [ ] Tornar a definição acionável: guia mestre para toda a produção de conteúdo
    - [ ] Alinhar às regras de copy da NTEX: "direto, punchy, zero buzzwords"; frases curtas, sem jargão, evitar metáforas
    - [ ] Referenciar `prompts/BUILD_SOCIAL_POST.md` e `prompts/LONGFORM_OUTLINE.md`
    - [ ] Registrar exemplos práticos (fazer/não fazer) e gatilhos de linguagem

- [ ] **Diretrizes visuais**:
  - [ ] Criar moodboard de referências
  - [ ] Definir paleta de cores
  - [ ] Selecionar tipografias
  - [ ] Estabelecer princípios de design

- [ ] **Planejamento de marketing**:
  - [ ] Selecionar canais prioritários
  - [ ] Definir orçamento por canal
  - [ ] Criar calendário editorial
  - [ ] Estabelecer estratégia de conteúdo

### 3. Validação
- [ ] Apresentar estratégia ao cliente
- [ ] Coletar feedback e ajustes
- [ ] Validar viabilidade técnica
- [ ] Obter aprovação final

### 4. Entrega
- [ ] Documentar estratégia completa
- [ ] Criar guia de marca
- [ ] Preparar briefings para produção
- [ ] Atualizar CRM com status

## O que entregamos ao final?
- **Artefatos gerados**: Estratégia de marca, guia visual, plano de marketing
- **Formatos**: PDF, Figma, Airtable
- **Status**: Estratégia aprovada, pronta para produção

## Quando está pronto e aprovado?
- [ ] Estratégia de marca documentada
- [ ] Guia visual aprovado pelo cliente
- [ ] Plano de marketing validado
- [ ] Briefings para produção criados
- [ ] Cronograma estabelecido

## Prazos e escalonamento (SLA)
- **Prazos típicos**: 5-7 dias úteis
- **Urgência**: Média
- **Escalonamento**: Diretor após 5 dias

## Como medimos sucesso?
- **KPIs**: Tempo de aprovação, número de revisões
- **Metas**: Máximo 2 revisões, aprovação em 7 dias
- **Fonte de dados**: Airtable, feedback do cliente

## O que é automático (e o que precisa de humano)?
- **Triggers**: Briefing aprovado no CRM
- **Ações**: Criação automática de documentos
- **Erros comuns**: Informações incompletas, cliente não disponível
- **Retentativas**: 2 tentativas de apresentação
- **Human-in-the-loop**: Criação de estratégia, aprovação do cliente

## Integrações
- **Airtable**: Base de dados do projeto
- **Figma**: Colaboração em design
- **Miro**: Sessões de ideação
- **Google Docs**: Documentação
- **CRM**: Atualização de status
